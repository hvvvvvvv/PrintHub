# PrintHub 服务管理面板

`PrintHubManager.exe` 是 PrintHub 的本机管理员工具。它需要管理员权限，
并默认管理与自身位于同一目录的 `PrintHub.exe`；也可以通过“浏览”选择
另一份服务程序。

## 使用方式

1. 选择服务程序，填写监听地址、LPD 设置和打印机映射。映射区域分为
   “RAW 端口映射”与“LPD 队列映射”两个分页；两者的打印机均可从下拉列表
   选择，也可以输入已安装的本机或连接打印机名称。
2. LPD 队列映射以“队列名 → 打印机名称”手工维护。队列名不区分 ASCII
   大小写，必须唯一；LPD 只接收已添加队列，且只有至少一条 LPD 映射时才
   启动监听。
3. 点击“安装/更新并启动”。若服务已安装，面板将停止、卸载、按页面参数
   重新安装并启动它。
4. 使用启动、停止、重启、卸载按钮进行日常管理；“打开日志目录”会打开
   服务程序同目录下的 `logs` 文件夹。

安装命令预览会显示完整命令行。线程数、LPD 端口、监听地址和日志级别即使
使用默认值也会明确写入服务配置；每条 RAW 映射和 LPD
`--lpd-queue "队列名=打印机名称"` 映射也会显示。LPD 没有单独的启用开关。
每个监听器最多等待 256 个客户端连接；LPD 控制文件默认最多 4 MiB。两个上限可在面板中调整，并会写入完整安装命令。

面板从 Windows 服务管理器读取已有服务的命令行并回填已知参数。若它发现
未知参数，会在更新前要求确认，防止无意中丢失该配置。

## 构建与兼容性

构建管理面板需要 Visual Studio 2022 的 **C++ MFC for latest v143 build
tools** 组件。构建脚本会在配置前检查该组件。发布版本为静态 MFC/静态 CRT
的 x86 和 x64 可执行文件；x86 版本以 Windows 7 SP1 x86 为最低目标。

在 Windows 7 SP1 上发布前，应验证 UAC 启动、安装、更新、停止、重启、
卸载、日志目录以及 RAW/LPD 打印流程。
